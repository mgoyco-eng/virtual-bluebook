VIRTUAL BLUEBOOK — FOCUS MODE REQUIRED UPDATE

Upload these three files to your existing GitHub repository and replace the current versions:
- index.html
- app.js
- styles.css

What changes:
- Students complete the required header first.
- Focus Mode must then be entered before the writing area unlocks.
- Assessment monitoring begins when Focus Mode starts.
- If Focus Mode is exited, the event is recorded and the writing area temporarily locks.
- Typed work is NOT deleted; students re-enter Focus Mode to continue.
- Final download is available only while Focus Mode is active.
- If full-screen mode is unavailable in the browser, the student is told to contact the teacher.

Suggested GitHub commit message:
Require Focus Mode to unlock Bluebook
